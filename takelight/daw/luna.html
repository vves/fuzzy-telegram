Connect TakeLight to LUNA

Send LUNA’s Mackie Control feedback to TakeLight to show record-ready and recording status on your Hue lights.

TakeLight 1.1.0+ · Arm, disarm, record, and stop verified with LUNA 2.0.4.4457 and two Hue lights, November 20, 2026.

1. Prepare TakeLight and Hue

Install TakeLight 1.1.0 or later on your Mac and launch it before opening your DAW. A Philips Hue Bridge and compatible lights must be on the same local network. Hue automation requires an active trial or Lifetime Hue Unlock.

In TakeLight, use Hue → Discovered Bridges to find your bridge, press its physical link button when prompted, then use Hue → Select Lights. If your trial has ended, choose Unlock TakeLight… first; use Restore Purchases for an existing purchase.

In TakeLight’s menu, choose DAW Connection → Other DAWs (MCU). This enables both MIDI ports and the full Mackie Control connection. The choice is saved across restarts.

MCU mode can be discovered by Logic if Logic is also running. Close Logic during this setup to keep the test isolated; choose Logic mode in TakeLight before returning to Logic.

2. Enable TakeLight in LUNA

  1. Open LUNA’s sidebar and choose Settings → Controllers. Some versions call the settings window Preferences.
  2. In an unused MIDI Control Surfaces row, choose the ports below.
  3. Enable the row’s On checkbox. Leave Focus Module and Extender unchecked for this basic setup.
  4. Open a session and create or select an audio track.

Port names are from TakeLight’s perspective: LUNA sends status to TakeLight In and receives replies from TakeLight Out.

3. Test arm, disarm, record, and stop

  1. Start stopped and disarmed. Your lights should show their normal lighting.
  2. Record-enable an audio track. The selected lights turn blue.
  3. Disarm the track. Normal lighting returns after a short settling delay.
  4. Arm the track again and start recording. After any count-in, the lights turn red.
  5. Stop recording. If the track remains armed, the lights return to blue.
  6. Disarm the track to return to normal lighting.

Use LUNA’s transport Record button and allow any count-in to finish. The light indicates recording status, not whether an audio waveform is loud or visible.

If the lights do not respond

  • TakeLight Out is missing: confirm Other DAWs (MCU) is selected. Logic mode provides no output port.
  • No status changes: verify the controller row is On, both port directions match the table, and the track is record-enabled.
  • Only some tracks trigger blue: MCU feedback follows the controller’s current track bank. Start with one visible audio track in the first bank.
  • Ports changed after a restart or mode switch: reselect them in LUNA’s Controllers settings.
  • Hue menus are disabled: unlock or restore access in TakeLight before pairing and testing.
  • Unexpected changes: close other DAWs that target TakeLight and run one copy of TakeLight.
