Logic Pro Record States

Logic Pro shows four different looks for a track's Record Enable ("R") button. Each one means something different, and TakeLight maps each to the matching light state so your recording light always reflects what Logic is actually doing.

  • R

    Off (Gray)

    The track is not armed for recording. This is the resting state.

    TakeLight: Idle
  • R

    Record-ready (Blinking Red)

    You have manually clicked the Record Enable button, and the track is waiting for you to hit record.

    TakeLight: Record Enabled
  • R

    Recording (Solid Red)

    You have engaged the master record button, and the track is actively capturing audio or MIDI.

    TakeLight: Recording
  • R

    Focused / Selected Track (Gray with a red letter "R")

    If no tracks are manually armed, Logic Pro automatically sets this state for the single track you currently have selected in the workspace. It is only a selection indicator, not a real record-enable.

    TakeLight: Idle

Source: Apple Logic Pro User Guide.
