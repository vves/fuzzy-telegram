Fender Studio Pro Setup

Connect TakeLight to Fender Studio Pro

Use Fender Studio Pro’s built-in Mackie Control support with TakeLight’s MCU connection mode.

Setup reference; hardware verification pending. Fender documents MCU support and the External Devices setup below. TakeLight’s Hue workflow has been verified in LUNA and Logic; it has not yet been tested in Fender Studio Pro. This guide covers Fender Studio Pro. MCU support in the separate, free Fender Studio app has not been verified.

1. Prepare TakeLight and Hue

Install TakeLight 1.1.0 or later on your Mac and launch it before opening your DAW. A Philips Hue Bridge and compatible lights must be on the same local network. Hue automation requires an active trial or Lifetime Hue Unlock.

In TakeLight, use Hue → Discovered Bridges to find your bridge, press its physical link button when prompted, then use Hue → Select Lights. If your trial has ended, choose Unlock TakeLight… first; use Restore Purchases for an existing purchase.

In updated builds, choose DAW Connection → Automatic and launch Fender Studio Pro. Alternatively, choose the Other DAWs (MCU) manual override; use that option in builds without Automatic. This uses the same MCU protocol as LUNA; Fender Studio Pro has its own setup screen. Quit Logic before testing, because Automatic gives Logic priority when both are open.

2. Add a Mackie Control device

  1. Open Fender Studio Pro’s Preferences → External Devices on macOS.
  2. Click Add… and choose the predefined Mackie Control device. Use the MCU device profile rather than a generic MIDI keyboard or MIDI-learn control surface.
  3. Set the MIDI ports as shown below, then confirm the device settings.
  4. Open a song and create or select an audio track in the controller’s current track bank.

Receive From corresponds to LUNA’s Input Device; Send To corresponds to LUNA’s Output Device. No physical Mackie hardware or hardware power-on button sequence is needed for TakeLight’s virtual ports.

3. Verify the light workflow

Check each step below in your Studio Pro version. These are the expected TakeLight responses, pending a hardware test in this DAW.

  1. Start stopped and disarmed. Your lights should show their normal lighting.
  2. Record-enable an audio track. The selected lights turn blue.
  3. Disarm the track. Normal lighting returns after a short settling delay.
  4. Arm the track again and start recording. After any count-in, the lights turn red.
  5. Stop recording. If the track remains armed, the lights return to blue.
  6. Disarm the track to return to normal lighting.

If the lights do not respond

  • Confirm Other DAWs (MCU), the built-in Mackie Control profile, and both port directions.
  • Start with one audio track visible to the surface’s current bank. Studio Pro’s remote bank determines which channels reach the MCU device.
  • If a port is unavailable, start TakeLight first and reopen External Devices to reselect the ports.
  • If recording works but arm feedback does not, note your Studio Pro version and contact support with the exact behavior; this integration is awaiting validation.
