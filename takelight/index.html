How TakeLight Works

TakeLight runs in the macOS menu bar and monitors configured local MIDI signals. When your configured state changes, TakeLight updates your selected Hue lights to match your studio mode.

Examples include "recording in progress" lighting to reduce interruptions, or visual state changes that communicate availability in shared spaces.

Current Feature Set

  • Automatic Hue Bridge discovery plus manual host entry fallback
  • Bridge pairing flow and persistent local bridge credentials
  • Selectable light targets (single room or multiple lights)
  • CoreMIDI-driven presence mapping and local automation actions

Roadmap

TakeLight is intentionally focused today on local MIDI-to-Hue studio automation. Next milestones expand ecosystem support while keeping the local-first philosophy.
